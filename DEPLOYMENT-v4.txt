GamerPointMC Bot Panel v4

REAL controls:
- panel-server/server.js starts/stops actual Node bot processes.
- Stop uses SIGTERM on the bot process. It never sends Minecraft /stop.
- WebSocket streams real stdout/stderr to the browser.
- Copy Log copies the actual displayed console.
- Each bot is independent.

Install:
1. npm install
2. Set environment variables:
   PANEL_TOKEN=<strong-random-token>
   VELOCITY_HOST=<your Velocity hostname/IP>
   VELOCITY_PORT=<Velocity port>
   BOT1_PASSWORD=<LimboAuth password for bot 1>
   BOT2_PASSWORD=<LimboAuth password for bot 2>
   BOT1 targets lobby; BOT2 targets survival.
3. Start panel:
   npm run panel
4. Open:
   http://HOST:PANEL_PORT

Important:
- Do not expose the panel without a strong PANEL_TOKEN and HTTPS/reverse proxy.
- The bot flow is connect -> /login -> detect auth success -> wait 30s -> /server target.
- If LimboAuth does not emit a success message compatible with the detector,
  the bot may need a detector matching your exact LimboAuth message/config.
- Geyser's NoSuchMethodError shown in your uploaded Velocity log is a separate
  Velocity/Geyser dependency issue and is not fixed by this bot panel.
